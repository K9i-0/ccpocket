# Changelog

## 1.0.0

First public release.

- Markdown AST, GFM parser (on `package:markdown`) with alerts, footnotes,
  `<details>`, inline HTML and math hooks, and a streaming-safe block splitter.
- `MarkdownView`, `SliverMarkdownView` and `SelectablePlainText`.
- Document-anchored selection across blocks and documents with touch handles,
  magnifier, edge autoscroll, keyboard and mouse support, and copy as plain
  text or Markdown.
- `MarkdownThemeData` and `MarkdownBuilders` for appearance and custom
  rendering, and a built-in context menu.
