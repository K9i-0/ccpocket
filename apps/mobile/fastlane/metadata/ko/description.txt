에이전트를 주머니에.

CC Pocket은 Codex, Claude, Antigravity 세 가지 코딩 에이전트를 하나의 채팅 중심 워크스페이스로 묶어줍니다. 에이전트는 내 컴퓨터의 셀프 호스팅 Bridge Server에서 실행되며, 휴대폰·태블릿·Mac 어디서든 작업 지시, 승인, diff 검토, 커밋과 푸시까지 이어갈 수 있습니다.

세 에이전트를 한곳에서
Codex, Claude, Antigravity 세션을 나란히 시작하고 이어가세요. 세션마다 모델, 사고 수준, 승인 모드를 전환하고 5시간·주간 플랜 사용량과 컨텍스트 사용률을 한눈에 확인하며, 사용하는 에이전트만 설정에서 켜고 끌 수 있습니다.

채팅 중심 UI와 실시간 활동 표시
세션마다 하나의 대화방에서 프롬프트, 응답, 질문 양식, 플랜 검토가 깔끔하게 이어집니다. 하단 실시간 활동 바에서 사고 미리보기, 명령 실행, 파일 편집, 백그라운드 작업 진행 상황을 바로 확인하세요. 이미지·스케치 첨부, 음성 입력, Markdown 자동완성도 지원합니다.

한 번의 탭으로 승인
실행 중인 여러 세션의 명령 실행, 파일 편집, MCP 요청, 구현 플랜 승인 대기를 한 목록에서 바로 처리하세요.

diff 검토, Git 작업, GitHub Issue/PR 연동
프로젝트 파일을 탐색하고 구문 강조 코드 diff와 이미지 diff를 확인하세요. diff의 여러 줄에 댓글을 달아 한 번에 AI 검토를 요청하고, 바로 stage·commit·push·revert하거나 git worktree로 병렬 작업을 분리할 수 있습니다. 앱 안에서 GitHub Issues와 PR(CI 상태·Draft 표시 포함)을 선택해 바로 세션을 시작할 수도 있습니다.

모바일 네트워크에도 끊김 없이
이동 중 연결이 끊기거나 사용량 제한에 도달해도 메시지가 대기열에 보관되어 재연결·리셋 후 자동 전송되며, 놓친 스트리밍 업데이트도 복구됩니다.

모든 화면에서 같은 작업 이어가기
iPhone, iPhone Duo, Android, iPad, macOS(및 실험적인 Linux·Windows 빌드)를 오가며 CLI나 앱에서 만든 세션을 그대로 이어가세요. 큰 화면에서는 세션 목록, 채팅, 파일 탐색기, Git 변경 내용을 나란히 볼 수 있습니다.

미디어 생성과 앱 내 재생
Codex Imagegen과 Antigravity로 이미지를 생성해 채팅과 갤러리에서 바로 확인하세요. 동영상(MP4/MOV)과 오디오(WAV/MP3) 파일도 앱을 벗어나지 않고 재생할 수 있습니다.

내 컴퓨터에서 안전하게 실행
Mac, Linux, Windows에서 Bridge Server를 실행하세요. QR 코드나 저장된 호스트로 연결하고 외부에서는 Tailscale로 안전하게 접속하며, SSH로 Bridge를 원격 관리할 수도 있습니다.

시작하기
1. 컴퓨터에 Node.js 22.19.0 이상과 Codex, Claude 또는 Antigravity 설치
2. npx @ccpocket/bridge@latest 실행
3. CC Pocket에서 QR 코드를 스캔하고 프로젝트 선택

연결 가능한 Bridge Server와 설정된 에이전트 계정이 필요합니다. CC Pocket은 무료로 사용할 수 있으며 선택적인 Supporter 구매로 개발을 지원할 수 있습니다. 에이전트 서비스 이용료는 별도입니다.
