에이전트를 주머니에.

휴대폰 채팅처럼 Codex와 Claude를 사용하세요. 작업을 요청하고, 다음 단계를 승인하고, 결과를 확인하세요. 에이전트는 내 컴퓨터에서 실행되고, 다른 기기에서도 같은 작업을 이어갈 수 있습니다.

채팅처럼 조작
세션마다 요청, 응답, 승인, 질문이 하나의 대화방에 모입니다. 이미지 첨부, 음성 입력, Markdown을 지원합니다. 여러 세션의 승인 대기도 목록에서 확인하세요.

기기를 바꿔도 이어서
휴대폰, 태블릿, Mac에서 CLI나 앱의 세션을 다시 여세요. 큰 화면에서는 채팅, 프로젝트 파일, Git 변경 내용을 나란히 볼 수 있습니다. macOS 네이티브 앱과 실험적인 Linux·Windows 데스크톱 빌드도 제공합니다.

연결이 끊겨도 입력은 유지
오프라인 메시지를 보관했다가 재연결 후 자동 전송하고, 놓친 응답도 복구합니다. 새 요청이나 승인을 실행하려면 Bridge Server에 연결되어 있어야 합니다.

만들고, 보고, 재생
Codex Imagegen으로 이미지를 만들고 채팅에서 확인하세요. 동영상과 오디오 파일도 앱 안에서 재생할 수 있습니다.

검토부터 반영까지
프로젝트 파일을 탐색하고 코드·이미지 diff를 검토하세요. stage, commit, push, revert를 지원하며, git worktree로 병렬 작업을 분리할 수 있습니다.

내 컴퓨터에서 실행
Mac, Linux, Windows에서 Bridge Server를 실행하세요. QR 코드나 저장된 호스트로 연결하고, 외부에서는 Tailscale을 사용할 수 있습니다. SSH로 Bridge를 관리할 수도 있습니다.

시작하기
1. 컴퓨터에 Node.js 20.18.1 이상과 Codex 또는 Claude 설치
2. npx @ccpocket/bridge@latest 실행
3. CC Pocket에서 QR 코드를 스캔하고 프로젝트 선택

연결 가능한 Bridge Server와 설정된 에이전트 계정이 필요합니다. CC Pocket은 무료로 사용할 수 있으며 선택적인 Supporter 구매로 개발을 지원할 수 있습니다. 에이전트 서비스 이용료는 별도입니다.

CC Pocket은 오픈 소스이며 Anthropic 또는 OpenAI의 공식 앱이 아닙니다.
