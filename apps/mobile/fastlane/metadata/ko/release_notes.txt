• Claude 백그라운드 작업: 턴이 끝난 후에도 실행 중인 작업을 세션의 "백그라운드에서 실행 중" 표시줄과 세션 카드의 배지로 확인할 수 있습니다.
• 작업 중 메시지 전송: Claude가 작업 중일 때 보낸 메시지를 현재 턴에 반영할지, 대기열에 넣을지 선택할 수 있습니다. 대기 중인 메시지는 반영, 편집, 취소할 수 있습니다.
• 세션 중에 Claude 모델, Effort, Fast 모드를 변경할 수 있으며, 세션 카드에 Effort와 Fast 모드가 표시됩니다.
• Claude의 어시스턴트 메시지에서 대화를 포크할 수 있습니다.
• 설정에 Claude와 Codex 플랜 사용량 카드를 추가하고, 세션 목록 요약에 Claude 사용량을 표시합니다.
• Claude 모델 이름과 설명을 Claude Code CLI와 동일하게 표시합니다.
• 고속 옵션을 포함한 Codex 서비스 티어를 선택할 수 있습니다.
• 수정: 서브에이전트 활동이 메인 채팅에 표시되거나 세션이 멈추는 문제, 다중 선택 질문에 "다음" 버튼이 없는 문제, 좁은 화면에서 권한·샌드박스 메뉴가 스크롤되지 않는 문제, 세션 시작이 거부되었을 때 "세션 생성 중..."에 멈추는 문제를 수정했습니다.
• 일부 기능은 Bridge 1.93.0 이상이 필요합니다.
