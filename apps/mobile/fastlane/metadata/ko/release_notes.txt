• 세션을 다른 에이전트에 인계할 수 있습니다. 채팅 메뉴에 Claude, Codex, Antigravity로의 "인계"가 추가되었습니다. 현재 에이전트가 인계 메모를 작성하고, 인계받은 에이전트가 같은 디렉터리에서 작업을 이어갑니다. 새 에이전트에 전달할 지시도 추가할 수 있습니다. 같은 권한 모드가 있으면 그대로 이어지고(auto는 auto 유지), 모델은 해당 에이전트의 마지막 시작 설정을 사용합니다. Bridge 1.119.0 이상이 필요합니다.
• Antigravity swarm(/swarm): swarm 보드의 게시물이 간결한 카드로 채팅에 표시되고, worker마다 고유한 색이 지정됩니다. 입력란 위의 Swarm 바에서 worker 목록과 작업 내용을 확인할 수 있습니다. 승인 요청에는 어느 worker의 요청인지 표시됩니다. Bridge 1.119.0 이상이 필요합니다.
• Bridge를 통해 기기 간에 공유됩니다: 고정한 세션과 프로젝트, 읽음 상태, 세션별 Claude 설정, 새 세션 시트의 초기 설정. Bridge 1.117.0 이상이 필요합니다.
• 알림이나 세션 링크를 열 때 세션을 찾는 동안 현재 화면을 벗어나지 않습니다. 세션을 사용할 수 없으면 전체 화면 오류 대신 메시지로 알려 줍니다.
• Codex 세션 메뉴에서 이름 변경, 스크린샷, 갤러리가 항상 영어로 표시되던 문제를 수정했습니다.
• 메시지 입력란에서 목록 항목 안의 코드 블록 뒤에 번호가 1부터 다시 매겨지던 문제를 수정했습니다.
• diff 뷰어에서 파일 경로가 올바르게 표시되지 않던 문제를 수정했습니다(공백이나 따옴표가 포함된 경로, "-- "로 시작하는 줄).
• Antigravity에서 방금 보낸 프롬프트가 그보다 먼저 도착한 출력 위에 표시될 수 있던 문제를 수정했습니다.
