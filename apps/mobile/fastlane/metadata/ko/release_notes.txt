• 컨텍스트 압축 후에는 최신 압축과 그 이후 메시지만 채팅에 표시합니다. 압축 카드에는 계기, 토큰 수, Claude 요약이 표시되며 이전 메시지를 읽기 전용으로 열 수 있습니다. 압축 중에는 채팅 끝에 "컨텍스트 압축 중…"이 표시됩니다.
• 불러온 기록보다 이전 메시지가 있을 때도 같은 화면에서 열 수 있습니다.
• 설정에 분할 화면 너비 슬라이더를 추가해 iPad mini 가로 Split View 같은 좁은 창에서도 세션 목록과 대화를 나란히 표시할 수 있습니다.
• iPad에서 플로팅 키보드를 사용할 때 최신 메시지가 입력창 바로 위까지 스크롤됩니다.
• Bridge가 API 키로 연결을 거부하면 재연결을 반복하지 않고, Bridge QR 코드를 다시 표시하는 명령과 QR 스캔·API 키 입력 버튼을 안내합니다. 향후 Bridge에서 API 키가 필수가 되는 것에 대한 준비입니다.
• API 키가 필요한 Bridge는 머신 목록에 표시됩니다.
• 새 기능에는 Bridge 1.103.0이 필요합니다.
