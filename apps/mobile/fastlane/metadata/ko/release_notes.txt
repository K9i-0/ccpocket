• 채팅 Markdown 표시 개편: 문단·목록·표·코드 블록을 넘나들며 텍스트를 이어서 선택할 수 있고, "마크다운으로 복사"로 중첩 목록과 표의 구조를 유지한 채 복사할 수 있습니다. 가로로 긴 표는 좌우로 스크롤되며, 스트리밍 중에도 표시가 안정적입니다.
• 최근 세션 필터 기억: 기간, 날짜 기준(수정일/생성일), 고정된 항목만, 본문 검색 설정이 앱을 다시 시작하거나 다시 연결해도 유지됩니다. 프로젝트 선택은 기기별로 따로 보관됩니다.
• 이미지 뷰어 통합: 채팅 이미지, 생성 이미지, 갤러리, 파일 미리보기에서 핀치, 더블 탭 확대, 이동을 같은 방식으로 사용할 수 있습니다. 한 번 연 이미지는 다음부터 더 빠르게 표시됩니다.
• 화면 글꼴이 기기의 시스템 글꼴로 바뀌었습니다. 코드는 고정폭 글꼴을 그대로 사용합니다.
• Swarm 코디네이터에 전용 문어 아이콘을 추가했습니다.
• 디버그 로그 화면에 검색, 레벨 필터, 복사, 공유를 추가했습니다.
