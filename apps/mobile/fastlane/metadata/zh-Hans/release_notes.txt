• Claude 后台任务：可通过会话中的"后台运行中"栏和会话卡片上的徽章，查看回合结束后仍在运行的任务。
• 工作中发送消息：Claude 工作时发送的消息，可选择插入当前回合或在队列中等待。队列中的消息可以插入、编辑或取消。
• 可在会话中更改 Claude 的模型、Effort 和 Fast 模式，并在会话卡片上显示 Effort 和 Fast 模式。
• 可从 Claude 的助手消息分叉对话。
• 设置中新增 Claude 和 Codex 套餐用量卡片，会话列表摘要中显示 Claude 用量。
• Claude 模型名称和说明与 Claude Code CLI 保持一致。
• 可选择 Codex 服务层级，包括高速选项。
• 修复：子代理活动出现在主聊天或导致会话卡住的问题、多选问题缺少"下一步"按钮的问题、小屏幕上权限和沙盒菜单无法滚动的问题，以及会话启动被拒绝时停留在"正在创建会话..."的问题。
• 部分功能需要 Bridge 1.93.0 或更高版本。
